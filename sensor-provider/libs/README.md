# Samsung Health Sensor SDK

Download the Samsung Health Sensor SDK from Samsung Developer and place its API
library here as `samsung-health-sensor-api.aar`. The binary is proprietary and is
intentionally excluded from source control.

The current supported library is Samsung Health Sensor SDK v1.4.1. Extract the
download and copy its `samsung-health-sensor-api.aar` into this directory without
renaming it. The `demo` flavor works without the AAR. The `samsung` flavor compiles
the real on-demand SpO2 implementation.
